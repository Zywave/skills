# When the loss tools are not available

Say it plainly, do not guess, and do not substitute outside numbers.

## What to tell the user

"I can't reach Zywave loss data in this session, so I can't look up [company]. Access to loss data is a separate, entitlement-gated product, so this usually means one of the items below."

Then offer the checks that apply, shortest first:

1. **Wrong account or context.** If a context or account switcher is available (for example a tool that lists contexts), list them and ask which one holds the loss data entitlement. Switching changes whose data is used, so ask before switching.
2. **Connection needs a refresh.** After a reconnect or context change, the client sometimes keeps the old tool list. Reconnect or refresh the connector, then try again.
3. **Entitlement not enabled.** Loss data access is purchased on top of the underlying product and may not be switched on for this account. Ask the Zywave account representative or the organization administrator to confirm the loss data entitlement.
4. **Sign-in expired.** Re-authenticate the Zywave connector.

Do not mention pricing. Do not name a numeric answer. Offer what remains possible: explaining what the skill returns, or helping prepare the access request.
